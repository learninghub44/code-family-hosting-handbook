# Code Family Hosting Handbook

A beginner-friendly, practical guide to servers, serverless computing, Vercel, Cloudflare Workers, VPS hosting, shared and dedicated hosting, containers, databases, deployment, security, and hosting costs.

## Project files

The complete static website project includes `index.html`, `styles.css`, `script.js`, and `assets/code-family-logo.svg`.

## Topics covered

The handbook covers servers and requests; static/shared hosting; serverless and edge computing; Vercel; VPS, dedicated and managed hosting; Docker and Kubernetes; databases and object storage; Cloudflare Pages, Workers and R2; Python hosting options including Render, Railway, PythonAnywhere, Koyeb, Google Cloud Run, DigitalOcean, Oracle Cloud Infrastructure and AWS; deployment choices; security; backups; and practical cost planning. Provider features, free allowances, availability and prices change, so verify current details in official documentation.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy

This is a static site and can be deployed to Cloudflare Pages, GitHub Pages, or another static hosting provider. No build step is required.
