# Code Family Hosting Handbook

A beginner-friendly, practical guide to servers, serverless computing, Vercel, Cloudflare Workers, VPS hosting, shared and dedicated hosting, containers, databases, deployment, security, and hosting costs.

## Project files

The complete static website project includes `index.html`, `styles.css`, `script.js`, and `assets/code-family-logo.svg`.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy

This is a static site and can be deployed to Cloudflare Pages, GitHub Pages, or another static hosting provider. No build step is required.
